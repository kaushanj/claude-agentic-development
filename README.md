# Pricing Lab Sub-agent

Implement:

calculate_total(unit_price, quantity, discount_percent=0)

Requirements:

- quantity must be a positive integer greater than or equal to 1
- invalid quantity values must raise ValueError
- discount_percent must be between 0 and 100 inclusive
- invalid discount values must raise ValueError
- total = unit_price * quantity with the discount applied
- return the result rounded to two decimal places

## Development

Changes should be developed on a feature branch and reviewed before merging into main.
